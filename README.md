# The Successor

An interactive story site for The Successor: a carryable robot (the lantern) that learns how an aging parent cares for their autistic adult child, helps every day, and teaches anyone who steps in.

Entry to the Stanford Center on Longevity Design Challenge, 2026–27.

## Editing

- **Words** (characters, scenarios, story beats, feature descriptions): `js/data.js`
- **Look** (colours, type, spacing): `css/styles.css`
- **Robot drawings and the scenario scene**: `js/lantern.js`
- **Page structure and fixed copy** (hero, problem, safeguards): `index.html`

No build step. Open `index.html` in a browser to preview. Pushing to `main` publishes to GitHub Pages.
